Rusty — learn Rust on your iPhone

Rusty teaches the Rust programming language from zero to a confident level: short theory cards, tasks you solve by tapping, practice, and an exam at the end of every section. Every example is checked with the real Rust compiler.

Help

What is free?

The first three sections are free in full. The full version unlocks every other section, all exams and practice with a single one-time purchase. There is no subscription.

I bought the full version, but sections are locked

Open Profile → Settings → Restore Purchases, signed in with the same Apple Account you used to buy it.

How do I get a refund?

Refunds are handled by Apple: reportaproblem.apple.com.

I found a mistake in a lesson

Write to f1xyegb@gmail.com with the section and task — we fix content in updates.
